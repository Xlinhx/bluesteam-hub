# Research Note: Video Experience & Programmatic Vector Animation

## Exploration of Educational Video Delivery
1. **Prototype Execution**:
   - The interactive prototype utilizes standard HTML5 video elements wrapped in custom, museum-grade chrome tailored for young learners (large playback toggles, chapter scrub markers, zero algorithmic clutter or external recommendation noise).
2. **Future Programmatic Animation Pipelines**:
   - For bespoke scientific explainers (e.g. molecular salinity, hydrostatic pressure diagrams), **Motion Canvas** (open-source TypeScript vector animation framework) is identified as the prime candidate.
   - Benefits: Real-time web preview, declarative programmatic layout, precision voice-over alignment, and headless frame-by-frame export without proprietary animation software.
3. **No Unneeded Dependencies Today**:
   - In adherence with our core philosophy ("Do not install speculative infrastructure"), Motion Canvas is documented as future research rather than introduced as an unneeded runtime dependency today.
