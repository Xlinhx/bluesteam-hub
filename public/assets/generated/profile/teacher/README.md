## Prompt template

Create ONE finished square watercolor avatar illustration for an adult TEACHER in BlueSTEAM ocean learning app. Subject: {subject}. Soft hand-painted watercolor and fine gouache on paper, matching a gentle children's illustrated ocean world but this character clearly has mature adult proportions, smaller thoughtful eyes, composed graceful posture, subtle reassuring smile, never baby/chibi. Gender neutral, dignified yet approachable. No clothes, no glasses, no beard, no human limbs, no text. Large strong recognizable silhouette legible at 32px. Entire creature inside a centered circular pale misty aqua watercolor ocean vignette with only a few understated aquatic strokes, nothing busy. Circle occupies 90 percent square, outer corners genuinely transparent. Creature occupies 75 percent circle, no cropping. Elegant restrained natural colors and soft edges. Single avatar only, no sheet, no UI.
